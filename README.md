## 🌸 Inspiration
Inspired by the kids who make games in Godot at the after-school care program Hannah works for, we wanted to show what they can make in the future with the basics that they learn.

## 🌸 Credits
Gabrielle Ajoc, Hannah Castillo, Kas Downey, Chloe Ubanan

## 🌸 What it does
A simple platformer game where Lenny jumps on platforms to reach for the stars!

## 🌸 How we built it
Built using Godot, version control with GitHub Desktop, and assets with Procreate and Clip Studio Paint

## 🌸 Challenges we ran into
Version control with GitHub Desktop, bugs with score changes, and the camera following the player

## 🌸 Accomplishments that we're proud of
Making a functioning game and utilizing everyone's strengths differently

## 🌸 What we learned
Do more research on the tools we used before the hackathon

## 🌸 What's next for Lenny Reaches for the Stars
Turning it into a level-based game with its own lore, making the storytelling aspect hook users into the game, instead of an infinite loop

## 🌸 To play
Using the latest version of Godot, download the files as a .zip and import into Godot
